PoW共识机制原理实现

| 项目  | 详细内容 |
| --- | --- |
| 参考课程 | 伯克利CS198 Lab1: Consensus Mechanism Implementation |
| 建议学时 | 2学时 |
| 前置知识 | 区块链数据结构、PoW/PoS共识核心原理 |
| 核心目标 | 理解共识机制如何解决分布式一致性问题，掌握PoW挖矿、难度调整、最长链原则的核心逻辑 |
| 实验环境 | Python 3.8+ |
| 详细实验步骤 | 1. 实现简化的区块结构：包含区块头（版本号、前区块哈希、默克尔树根、时间戳、难度目标、Nonce）、区块体（交易列表）<br>2. PoW挖矿算法实现：<br> - 设定难度目标（哈希值前导零数量）<br> - 遍历Nonce值，计算区块哈希，找到符合难度目标的Nonce<br> - 实现难度调整机制：根据出块时间动态调整难度目标，稳定出块间隔<br>3. 最长链原则模拟：创建两个分支链，验证节点始终选择累计工作量最大的最长链<br>4. （略过）简化的PoS共识实现：根据节点质押的代币数量分配区块打包权，模拟区块生成与验证流程 |
| 验收标准 | 1. 成功挖出符合难度要求的区块，区块哈希满足前导零要求<br>2. 难度调整机制能根据出块时间正确调整难度，稳定出块间隔<br>3. 能正确模拟最长链原则，说明分叉的产生与解决逻辑 |
| 拓展进阶任务 | 1. 模拟51%算力攻击的场景，说明攻击成功的条件与成本<br>2. 实现DPoS共识的委托节点选举与区块轮流打包逻辑 |
