| 参考课程   | MIT 6.890 Lab2: Bitcoin UTXO & Transaction Model                                                                                                                                                                                                                                 |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 建议学时   | 2学时                                                                                                                                                                                                                                                                              |
| 前置知识   | 比特币UTXO模型、交易结构、数字签名验证                                                                                                                                                                                                                                                            |
| 核心目标   | 深入理解比特币UTXO模型的核心逻辑，掌握比特币交易的合法性验证规则                                                                                                                                                                                                                                               |
| 实验环境   | Python 3.8+、比特币区块链浏览器Blockchair                                                                                                                                                                                                                                                  |
| 详细实验步骤 | 1. 用Python实现一个简化的UTXO池，支持UTXO的添加、查询、删除操作<br>2. 构建一笔标准的P2PKH比特币交易：<br> - 输入：引用一笔未花费的UTXO，提供解锁脚本（签名+公钥）<br> - 输出：生成接收方UTXO+找零UTXO，设置锁定脚本<br>3. 实现交易合法性验证逻辑：<br> - 验证输入UTXO未被花费<br> - 验证解锁脚本与锁定脚本匹配，签名合法<br> - 验证输入金额≥输出金额+手续费<br>4. 在Blockchair中查询一笔真实的比特币交易，解析其输入输出结构，对比自己实现的模拟交易 |
| 验收标准   | 1. 实现的UTXO池能正确管理未花费输出，无双重花费漏洞<br>2. 构建的交易能通过所有合法性验证，正确处理找零逻辑<br>3. 能完整解析真实比特币交易的UTXO结构，说明每一笔输入输出的作用                                                                                                                                                                              |
| 拓展进阶任务 | 1. 实现2/3多签交易的构建与验证逻辑<br>2. 模拟隔离见证（SegWit）的交易结构优化，说明其解决的问题                                                                                                                                                                                                                        |
