| 项目  | 详细内容 |
| --- | --- |
| 参考课程 | IBM Hyperledger官方课程、MIT 6.890 Lab6: Permissioned Blockchain |
| 建议学时 | 2学时 |
| 前置知识 | 联盟链核心特征、Fabric架构（节点、通道、链码） |
| 核心目标 | 掌握企业级联盟链的环境搭建、通道配置与智能合约（链码）开发流程 |
| 实验环境 | Docker、Docker Compose、Fabric 2.5官方测试网络、Go/Node.js |
| 详细实验步骤 | 1. Fabric测试网络搭建：<br> - 拉取Fabric官方镜像，启动2个组织、4个Peer节点、1个Orderer节点、1个CA节点的测试网络<br> - 创建应用通道（Channel），将2个组织的Peer节点加入通道<br>2. 链码开发与部署：<br> - 编写基础的资产链码（实现资产的增删改查，对应供应链/存证场景）<br> - 完成链码的打包、安装、审批、提交全流程<br>3. 链码交互测试：通过CLI工具调用链码，完成资产创建、查询、更新、删除操作，验证账本状态的同步<br>4. 多组织权限控制：配置链码的背书策略，要求交易需2个组织共同背书才能生效 |
| 验收标准 | 1. 成功启动Fabric测试网络，创建通道并将所有节点加入通道<br>2. 成功部署链码，完成资产的全生命周期操作，账本状态同步正确<br>3. 能正确配置背书策略，验证不符合背书策略的交易无法上链 |
| 拓展进阶任务 | 1. 搭建多通道的Fabric网络，实现不同业务的数据隔离<br>2. 用Fabric SDK编写前端应用，实现与链码的可视化交互 |
